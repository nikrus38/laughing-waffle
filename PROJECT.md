# PROJECT.md — «ФинТвин»

Полное описание того, что уже сделано: что видит комиссия, как это устроено внутри
и что можно трогать без страха всё сломать. Документ для команды: читается сверху
вниз за 15 минут, без знания кода.

---

## 1. В двух словах

**ФинТвин** — Telegram Mini App и веб-приложение, которое показывает «Университет 4.0»
в действии. Это не презентация и не макет: комиссия открывает ссылку, входит
демо-студентом и проходит полный цикл — подбор задачи, отклик, рост компетенций,
начисление FinCoin, проверка этики алгоритма.

| Параметр | Значение |
| --- | --- |
| Публичный адрес | https://fintwin.duckdns.org |
| Консоль | https://fintwin.duckdns.org/app/ |
| Статус платформы | https://fintwin.duckdns.org/status/ |
| Документация API | https://fintwin.duckdns.org/docs/ |
| Сервер | VPS 2.27.42.70, Ubuntu 26.04, Docker Compose |
| Срок сдачи | 21 декабря 2026 |

## 4. Архитектура

```
Браузер / Telegram
        │
        ▼
Caddy  ── HTTPS (Let's Encrypt, автопродление)
        │   статика /static, проксирование
        ▼
Django + DRF  ──►  PostgreSQL 16
   │                 (демо: SQLite)
   ├── /            публичный сайт (шаблоны + landing.css)
   ├── /app/        React-консоль (SPA из dist/)
   ├── /api/        JSON для консоли
   ├── /admin/      панель управления
   └── /status/     мониторинг доступности
```

**Разделение слоёв в коде:** `src/domain` — чистая логика без React (матчинг, реестр,
этика, профиль); `src/features` — экраны; `src/shared` — общие компоненты и стор.
Поэтому правила можно тестировать без браузера, а на защите объяснять одной схемой.

**Где считаются правила:** на сервере. Процент совпадения, дневные лимиты FinCoin,
хеш-цепочка реестра и этический фильтр живут в Django, а фронтенд их только показывает.
Это защищает от накруток и делает демо воспроизводимым.

## 7. Консоль студента

Нижняя навигация на телефоне: Главная, Двойник, Матч, Кошелёк, Этика.
Остальные разделы — в сайдбаре и в меню «+» на десктопе.

### 7.1 Обзор
Приветствие, «Индекс бесшовности» (0–100), карточки «Сегодня» от ИИ с чипом ценности
и кнопкой «Почему так?». На десктопе — сводка FinCoin, активность за 17 недель,
тепловая карта и топ действий.

### 7.2 Цифровой двойник
Радар из 8 компетенций: две линии — «сейчас» и «цель», подсвечена зона ближайшего
развития. Переключатель «Оценки / Компетенции» показывает разницу между средним
баллом и навыками. Микромодули на 15–45 минут с мини-прохождением из трёх вопросов:
после него радар пересчитывается по формуле убывающей отдачи, а сервер начисляет
+20 FinCoin за данные для обучения ИИ.

### 7.3 ИИ-сват (матчинг)
Стопка карточек задач R&D. Формула процента: 40% навыки, 30% зона роста, 20%
интересы, 10% свободные часы. Жесты вправо/влево/вверх и дублирующие кнопки —
доступность важнее жестов. Этическое правило **MATCH-001** гарантирует, что в первой
тройке всегда есть задача на вырост. После отклика — план первого месяца.

### 7.4 Кошелёк FinCoin
Баланс, уровень, лента транзакций с основанием и чипами ценностей. Начисления —
шесть действий из задания (20/100/50/40/150/70), дневные лимиты, запрет дублей.
Реестр хранит хеш предыдущей записи; кнопка «Проверить цепочку» пересчитывает SHA-256
и показывает первую повреждённую запись, если её подменить.

### 7.5 Этика ИИ
10 ценностей, у каждой — «как зашито в алгоритм» с идентификатором правила и пример
«без этики / с этикой». «Симулятор искушения»: ползунок «хочу баллов побыстрее»,
алгоритм всё равно ведёт по пути развития. «Журнал решений ИИ» — что рассматривали,
что отклонили и какая ценность сработала. Официальные формулировки ценностей не
переданы, поэтому поле `text` пустое и интерфейс пишет «текст уточняется».

### 7.6 Диагностика (этап 1)
Три вкладки: тепловая карта 20 барьеров (административные / информационные /
культурные × пять стадий, реальные цифры 34,7% и 55%), схема потоков данных с
этическим фильтром на каждом ребре, прогноз спроса на навыки со слайдером 1–5 лет.

### 7.7 Траектория (этап 2)
Три сценария А/Б/В, выбрана В «Сингулярность кампуса»: бесшовность опыта. Радар
сравнения по пяти критериям, блок «Почему В».

### 7.8 Радар патентов (этап 3)
Пузырьковая диаграмма тем: зрелость × потенциал × число патентов. Все числа —
демо. У темы есть «Предложение кафедре».

### 7.9 Декомпозиция (этап 3)
Партнёр формулирует задачу — платформа раскладывает её на учебные кейсы по курсам
1–4 с суммой FinCoin на каждом узле. Три готовых примера и генератор по тегам.

### 7.10 Сценарии и защита (этап 6)
`/app/demo`: три сценария в один клик, таймер на 7–10 минут, суфлёр и «Сбросить демо».

## 8. Профиль и настройки

Отдельная вкладка `/app/profile` и плашка, которая открывается по клику на аватар
(мобильная шапка, аватар на десктопе, блок внизу сайдбара).

**Что можно изменить:** отображаемое имя, курс 1–4, интересы (до 8, с подсказками
из тегов задач), свободные часы 4–30 в неделю. Сохранение — через `PATCH /api/me/`,
есть индикатор «есть несохранённые изменения», отмена и тост «Профиль сохранён».
Интересы и часы не декоративные: они участвуют в матчинге (interestFit и loadFit).

**В плашке профиля:** профиль и настройки, цифровой двойник, сценарии защиты,
переключение демо-профиля, выход из аккаунта.

## 10. Статус платформы `/status/`

Страница показывает не картинку, а настоящие проверки, которые выполняются при
каждом открытии: API, база данных (`SELECT 1`), целостность хеш-цепочки FinCoin,
наличие сборки консоли.

- Uptime за 30 дней по каждому компоненту; дни без замеров подписаны «нет данных»,
  а не 100%.
- График времени ответа, таблица текущих проверок, инциденты.
- Автообновление раз в 30 секунд и кнопка «Проверить сейчас».
- Машиночитаемый срез: `/api/status/`.
- На сервере стоит systemd-таймер: `monitor_ping` каждые 5 минут, чтобы история не
  прерывалась ночью; записи старше 90 дней удаляются.

## 12. Админка `/admin/`

Своя панель управления с русскими заголовками и демо-блоком на главной.

- Разделы идут по рабочему процессу: ценности → правила этики → микромодули →
  задачи партнёров → отклики → двойники → реестр FinCoin → журнал решений ИИ →
  барьеры → инциденты → мониторинг.
- Поиск и фильтры везде; отклики студентов встроены в карточку задачи.
- **Журнал решений ИИ и замеры мониторинга — только чтение.** Журнал, который можно
  править, перестаёт быть журналом.
- У инцидентов есть действие «Отметить восстановленным сейчас».
- Суперпользователь создаётся командой `seed_admin` из пароля в окружении.

## 13. PWA и Telegram

- Manifest, иконки, маскируемая иконка, скриншоты, shortcuts на разделы.
- Service worker: офлайн-оболочка и страница `/offline/` с честным текстом.
- Установка на рабочий стол/домашний экран; баннер установки появляется только
  когда браузер реально предлагает установку.
- Внутри Telegram работает та же сессия; `initData` проверяется сервисом
  `core.services.telegram`, данные пользователя Telegram не сохраняются.
- В браузере вне Telegram всё работает так же, без ошибок в консоли.

## 14. API кратко

Все ответы — JSON в camelCase. Авторизация — cookie-сессия Django, для POST/PATCH
нужен заголовок `X-CSRFToken` (cookie выдаёт `/api/csrf/`).

```
POST /api/auth/register/     POST /api/auth/login/      POST /api/auth/logout/
GET  /api/me/                PATCH /api/me/
GET  /api/bootstrap/                       всё для первого экрана
GET  /api/tasks/             POST /api/tasks/{code}/apply/
POST /api/modules/{code}/complete/
GET  /api/ledger/            POST /api/ledger/award/    POST /api/ledger/verify/
GET  /api/ethics/
GET  /api/diagnostics/barriers/            GET /api/diagnostics/forecast/
POST /api/decompose/
POST /api/demo/reset/
GET  /api/csrf/  /api/health/  /api/status/
```

Полные примеры — на `/docs/`.

## 15. Данные и честность

- Всё вымышленное помечено `isMock` / «демо-данные»: персоны, задачи, патенты,
  показатели мониторинга до первого замера.
- Реальны только: цифры диагностики **34,7%** и **55%** и суммы FinCoin
  **20 / 100 / 50 / 40 / 150 / 70**.
- Официальные формулировки 10 ценностей не выдумываются: `official_text = null`,
  интерфейс пишет «текст уточняется».
- Персональные данные реальных людей и логотипы компаний не используются:
  партнёры подписаны «Крупный банк (пример)».

## 20. Пятиминутный маршрут для группы

1. Открыть главную, пролистать до блока этики.
2. `/demo-login/` → консоль студента: обзор, индекс бесшовности.
3. «Матч»: свайп задачи, отклик, план первого месяца.
4. «Двойник»: пройти микромодуль, увидеть рост и +20 FinCoin.
5. «Кошелёк»: история, лимиты, «Проверить цепочку».
6. «Этика»: симулятор искушения и журнал решений.
7. Аватар → «Профиль партнёра»: отдельный кабинет, декомпозиция задачи.
8. `/status/` и `/docs/` — инженерная часть проекта.
9. `/admin/` — данные, на которых всё работает.
