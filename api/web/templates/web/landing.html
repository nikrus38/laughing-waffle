Что вы получите

Посмотреть возможности Выбрать роль
  • Прозрачный матчинг: видно каждый фактор совпадения
  • Задача на вырост в первой тройке — по правилу MATCH-001
  • FinCoin только за вклад, с лимитами и проверяемым реестром
  • Журнал решений ИИ: что рассмотрели, что отклонили и почему
  • Один интерфейс в браузере, Telegram и как приложение

Работает везде, где есть браузер

Открывается как приложение

Один и тот же продукт запускается в Telegram, в браузере и как PWA: иконка на рабочем столе или домашнем экране, отдельное окно без адресной строки.

Попробовать сейчас Как установить
Windows / macOS / Linux

Кнопка «Установить» в Chrome или Edge — приложение открывается в своём окне.

Android

«Добавить на главный экран» в Chrome. В дальнейшем — упаковка в APK.

iOS / iPadOS

Safari → «Поделиться» → «На экран Домой». Ограничения платформы описаны честно.

Telegram

Mini App по ссылке: тот же интерфейс, без установки и без чтения данных профиля.
