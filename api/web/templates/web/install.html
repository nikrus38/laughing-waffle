Инструкции

Как установить

Windows
  1. Откройте сайт в Chrome или Edge.
  2. Нажмите иконку установки в адресной строке.
  3. Готово: иконка появится в «Пуске» и на панели задач.
macOS
  1. Откройте сайт в Chrome или Edge.
  2. Меню браузера → «Установить приложение».
  3. Приложение появится в Launchpad.
Linux
  1. Chrome или Chromium: иконка установки в адресной строке.
  2. Приложение добавится в меню программ.
  3. Работает в отдельном окне без вкладок.
Android
  1. Откройте сайт в Chrome.
  2. Меню → «Добавить на главный экран».
  3. Запуск — на весь экран, без адресной строки.
iOS / iPadOS
  1. Откройте сайт в Safari.
  2. Кнопка «Поделиться» → «На экран Домой».
  3. Ограничения платформы: без установки из App Store и с ограниченным push.
Telegram
  1. Откройте бота с Mini App.
  2. Нажмите кнопку запуска приложения.
  3. Интерфейс тот же, данные профиля Telegram не читаются.

Честно о технологии

Что такое PWA

Progressive Web App — сайт, который браузер умеет устанавливать как приложение. Он кэширует оболочку и открывается быстрее, но данные (реестр, матчинг) остаются серверными.

  • Иконка и отдельное окно без адресной строки
  • Работает офлайн для оболочки, но не для начислений
  • Обновляется автоматически, без магазина приложений
  • Требует HTTPS — это требование браузеров, а не наше

Чего не будет

  • Настоящего UWP-приложения и установки в Microsoft Store «из коробки»
  • iOS-приложения вне App Store
  • Полной офлайн-работы для FinCoin и матчинга
