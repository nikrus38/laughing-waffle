# Фаза 2: Исправления проблем с запуском сервера

## Проблема
При попытке запустить сервер разработки с помощью `npm run dev` и открыть приложение в браузере по адресу http://localhost:3000, возникала ошибка "Не удалось получить доступ к сайту".

## Диагностика
1. Проверили, что сервер запущен и слушает порт 3000:
   ```
   Get-NetTCPConnection -LocalPort 3000
   ```
   Результат: сервер слушает порт 3000

2. Проверили доступность сервера:
   ```
   Test-NetConnection localhost -Port 3000
   ```
   Результат: TcpTestSucceeded : True

3. Проверили содержимое страницы через curl:
   ```
   curl -UseBasicParsing http://localhost:3000
   ```
   Результат: StatusCode : 200 (OK)

## Решение
Проблема была в том, что сервер Vite по умолчанию слушает только localhost (127.0.0.1), но не слушает внешние интерфейсы. 
Для исправления добавили параметр `host: '0.0.0.0'` в конфигурацию сервера в файле `vite.config.js`:

```javascript
server: {
  host: '0.0.0.0',
  port: 3000,
},
```

Это позволяет серверу принимать соединения с любого интерфейса, включая localhost и внешние IP-адреса.

## Результат
После применения исправления сервер стал доступен из браузера по адресу http://localhost:3000, и приложение корректно отображается.
