# Фаза 2: Ядро продукта - План

## Цели фазы
1. Создать оболочку приложения и навигацию
2. Разработать главную страницу ("ФинОС")
3. Реализовать модуль "Цифровой двойник"
4. Создать модуль "ИИ-сват" с жестами и запасными кнопками
5. Обеспечить сквозной сценарий "матч → отклик → обновление двойника"

## Задачи по компонентам

### 1. Оболочка и навигация
- Создать основной layout приложения
- Реализовать нижнюю панель навигации (5 вкладок: Главная, Двойник, Матч, Кошелёк, Этика)
- Добавить верхнюю панель с аватаром, балансом FinCoin и переключателем роли
- Настроить роутинг между основными разделами
- Реализовать TelegramProvider для интеграции с Telegram Mini Apps

### 2. Главная страница ("ФинОС")
- Приветствие по профилю двойника
- Блок "Сегодня" с 3 карточками следующих шагов от ИИ
- Индекс бесшовности (кольцевой индикатор)
- Сетка карточек-входов в модули
- Онбординг для первого запуска (3 экрана)

### 3. Модуль "Цифровой двойник"
- Радар из 8 компетенций (визуализация)
- Переключатель "Оценки / Компетенции"
- Список микромодулей с возможностью прохождения
- Анимация обновления радара после прохождения модуля
- Уведомление о данных для ИИ и начисление +20 FinCoin

### 4. Модуль "ИИ-сват"
- Стопка карточек задач R&D от партнёров
- Жесты: вправо (отклик), влево (пропустить), вверх ("хочу сложнее")
- Альтернативные кнопки для доступности
- Экран "План первого месяца" после отклика
- Маркировка задач "на вырост" и этический фильтр

## Технические задачи

### 1. State Management (Zustand)
- Создать хранилище для основного состояния приложения
- Реализовать состояние пользователя (двойник, баланс, история)
- Настроить состояние модулей (диагностика, траектория и т.д.)

### 2. Компоненты UI
- Создать базовые компоненты (кнопки, карточки, модальные окна)
- Разработать компоненты для радара компетенций
- Создать компоненты для жестов (swipeable cards)
- Реализовать компоненты для индекса бесшовности

### 3. Интеграция с Telegram
- Настроить TelegramProvider
- Реализовать BackButton синхронизацию с роутером
- Настроить MainButton для основных действий
- Отключить вертикальные свайпы где необходимо
- Настроить haptics для взаимодействий

### 4. Адаптивность и доступность
- Адаптация под мобильные вьюпорты (390×844, 360×640)
- Поддержка safe area устройств
- Контрастность согласно WCAG AA
- Поддержка prefers-reduced-motion
- Управление с клавиатуры

## Порядок реализации

### Неделя 1 (начало)

4. Интеграция с Telegram

### Неделя 3 (завершение)
1. Модуль "ИИ-сват" с жестами
2. Запасные кнопки и доступность
3. Полное тестирование сценария
4. Финальная полировка и оптимизация

## Критерии готовности

### Для каждого компонента:
- Работает в Telegram и в браузере
- Есть пустое, загрузочное и ошибочное состояния
- Все демо-данные помечены
- У решений ИИ есть кнопка "Почему так?" и запись в журнале этики
- Проверено скриншотом на двух вьюпортах
- Нет предупреждений линтера и типов
- Тексты в copy.ts

### Для продукта в целом:
- Сквозной сценарий "матч → отклик → обновление двойника" проходит в Playwright
- Все 6 этапов задания видны в интерфейсе
- "Сбросить демо" возвращает в чистое состояние
- Сборка стабильно открывается по ссылке
