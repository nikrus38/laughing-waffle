## Шрифты (страница 15)

- **Open Sans** — основной наборный шрифт, начертания Light–Bold, включая курсив.
  Используется для заголовков и основного текста.
- **Golos Text** — дополнительный наборный шрифт, Regular–Bold.
- Акцидентный шрифт применяется только в заголовках, не в наборе длинного текста.

В продукте: заголовки — Open Sans (600/700), интерфейсный текст — Golos Text,
цифры денег и процентов — табличные (`tabular-nums`).

## Правила логотипа (раздел «Охрана логотипа»)

Из брендбука: нельзя воспроизводить логотип контуром, деформировать, менять
пропорции, удалять элементы, менять шрифт в шрифтовом блоке, добавлять тени и
выдавливание, использовать на неконтрастном фоне. Охранное поле вокруг логотипа
обязательно.

В продукте: логотип стоит только на светлом фоне, без обводок и эффектов,
с отступами; в тёмном футере — на белой подложке. В консоли используется
компактный знак-эмблема (иконка PWA), чтобы не дублировать полный логотип.

## Маскот

Финик — официальный маскот университета. В интерфейсе демо пока не используется:
его появление нужно согласовать с командой и преподавателем. Исходники лежат
в `mascot/`.

## Правовой статус

Это официальные материалы Финансового университета. Они используются в учебном
проекте «ФинТвин» и не предназначены для коммерческого распространения.
При публикации вне университета нужна ссылка на источник и согласование
с Управлением по связям с общественностью.
