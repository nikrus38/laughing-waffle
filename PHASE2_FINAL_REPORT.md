## Исправления проблем с запуском

### Проблема
При попытке запустить сервер разработки с помощью `npm run dev` и открыть приложение в браузере по адресу http://localhost:3000, возникала ошибка "Не удалось получить доступ к сайту".

### Диагностика и решение
1. Проверили, что сервер запущен и слушает порт 3000
2. Проверили доступность сервера через различные инструменты
3. Обнаружили две проблемы:
   - Сервер по умолчанию слушает только localhost (127.0.0.1)
   - В файле App.jsx использовались HTML-entities вместо обычных символов
4. Исправили конфигурацию Vite, добавив параметр `host: '0.0.0.0'`:

```javascript
server: {
  host: '0.0.0.0',
  port: 3000,
},
```

5. Исправили файл App.jsx, заменив HTML-entities на обычные символы:
   - `&lt;` на `<`
   - `&gt;` на `>`
   - `&quot;` на `"`

### Результат
После применения исправления сервер стал доступен из браузера по адресу http://localhost:3000, и приложение корректно отображается.
