# ФинТвин - MVP Университета 4.0

Telegram Mini App для демонстрации концепции "Финуниверситета 4.0".

## Описание проекта

Проект "Архитектура Финуниверситета 4.0: от цифрового следа к экосистеме смыслов" представляет собой интерактивный MVP, демонстрирующий работу Университета 4.0, где технологии (ИИ, Big Data, цифровые двойники) служат развитию человека, а 10 корпоративных ценностей университета работают как этический фильтр алгоритмов.

## Основные компоненты

1. **Диагностика** - тепловая карта болевых точек и схема потоков данных
2. **Траектория** - выбор направления развития университета
3. **Цифровой двойник** - профиль студента с компетенциями
4. **ИИ-сват** - система подбора задач от партнеров
5. **FinCoin** - экономическая система с реестром транзакций
6. **Этика ИИ** - встроенные корпоративные ценности в алгоритмы

## Технический стек

- Vite + React 18 + TypeScript
- Tailwind CSS
- React Router (HashRouter)
- Zustand для состояния
- Recharts для графиков
- Telegram Mini Apps SDK

## Установка и запуск

```bash
npm install
npm run dev
```
