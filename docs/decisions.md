# Журнал технических решений

## Фаза 0: Окружение и каркас

### Решения по инструментам:

| Инструмент | Статус | Комментарий |
|------------|--------|-------------|
| frontend-design | Доступен | Будет использоваться для создания уникального дизайна |
| Playwright | Доступен | Для e2e тестирования и скриншотов |
| Context7 | Доступен | Для документации по библиотекам |
| GitHub | Доступен через CLI | Для управления репозиторием и CI/CD |
| docx, pptx | Недоступны | Будем использовать альтернативные методы для документации |
| Figma | Опционально | Если будут предоставлены макеты |
| Веб-поиск | Ограничен | Используем доступные источники |

### Технический стек:

1. **Фронтенд**: Vite + React 18 + TypeScript
2. **Стилизация**: Tailwind CSS
3. **Роутинг**: React Router (HashRouter для GitHub Pages)
4. **Состояние**: Zustand
5. **Графики**: Recharts
6. **Анимации**: CSS-анимации
7. **Telegram**: @telegram-apps/sdk-react
8. **Тестирование**: Vitest (unit), Playwright (e2e)
9. **Линтинг**: ESLint + Prettier
10. **Деплой**: GitHub Pages

### Что сделали и почему (простыми словами):

1. Проверили доступные инструменты - важно знать, что можем использовать
2. Создали структуру директорий - для удобной организации кода
3. Подготовили документацию по источникам - чтобы понимать контекст проекта
4. Определили технический стек - выбранные технологии подходят для задач проекта

## Фаза 1: Домен и данные

### Решения по архитектуре:

1. **Чистая архитектура**: Бизнес-логика отделена от фреймворков и UI
2. **Моковые данные**: Все данные статические для демонстрации
3. **Локальное состояние**: Используется localStorage для хранения состояния между сессиями
4. **Типизация**: TypeScript для обеспечения качества кода

### Что сделали и почему (простыми словами):

1. Создали модели данных - чтобы понимать структуру информации в системе
2. Разработали алгоритмы - для реализации ключевых функций (матчинг, двойник, реестр, этика)
3. Написали тесты - чтобы убедиться, что код работает правильно
4. Подготовили документацию - чтобы объяснить, как всё устроено
