# Вопросы команде для продолжения работы

## Срочные вопросы (необходимы для продолжения)

1. **Корпоративные ценности университета**
   - Каковы официальные формулировки 10 корпоративных ценностей Финансового университета?
   - Это критично для реализации модуля "Этика ИИ" и правил этического фильтра.

2. **Исходные данные для этапа 1**
   - Каков источник цифр 34,7% (кооперация с вузами) и 55% (кооперация с поставщиками)?
   - Есть ли дополнительные данные для тепловой карты барьеров и схемы потоков данных?

## Важные вопросы (для планирования)

3. **Дизайн и визуальный стиль**
   - Будет ли использоваться фирменный стиль университета в дизайне?
   - Есть ли предпочтения по цветовой палитре, шрифтам или общему стилю?

4. **Распределение ролей в команде**
   - Кто отвечает за дизайн и тексты (copy.ts)?
   - Кто отвечает за аналитику и содержание этапов 1-3?
   - Кто отвечает за тестирование и сценарии?
   - Кто отвечает за презентацию и защиту?

5. **Технические детали**
   - Будет ли создан бот и мини-приложение в BotFather?
   - Есть ли предпочтения по хостингу (уже подтверждено: GitHub Pages)?

## Вопросы для уточнения (для полноты картины)

6. **Обращение в интерфейсе**
   - Подтверждаем использование обращения на "вы" в интерфейсе?

7. **Дополнительные данные**
   - Есть ли еще какие-либо исходные данные для этапов 1-3?
   - Есть ли примеры задач от партнеров или микромодулей?

8. **Сроки и приоритеты**
   - Есть ли особые приоритеты в реализации функциональности?
   - Нужно ли сосредоточиться на каких-то конкретных модулях в первую очередь?

## Предложения по умолчанию

Для продолжения работы мы можем использовать следующие временные решения:

1. Для ценностей университета - использовать общие формулировки, характерные для российских вузов, с пометкой "[ВСТАВИТЬ ОФИЦИАЛЬНЫЙ ТЕКСТ]"
2. Для данных этапа 1 - использовать экспертные оценки с явной маркировкой как "демо-данные"
3. Для дизайна - следовать рекомендациям из раздела 11 документа CLAUDE.md с использованием навыка frontend-design
